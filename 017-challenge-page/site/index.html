The 5 days

20 Minutes A Day. 1 Thing Done Each Day.

  1. Monday

    Pick the problem

    Choose 1 problem you solve better than most. Done when: 1 sentence.

  2. Tuesday

    Name the outcome

    Turn it into a result with a timeframe. Done when: a headline.

  3. Wednesday

    Build the offer

    Live session, 12pm. What is included and what is not. Done when: 5 bullet points.

  4. Thursday

    Set the price

    Use the 3-number method. Done when: 1 price you can say aloud.

  5. Friday

    Test it

    Send it to 3 real people. Done when: 3 messages sent.
